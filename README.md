# Stellive 모드

마인크래프트 **26.3** / **Fabric** 모드입니다.

## 추가되는 아이템

| 아이템 | 텍스처 | 공격력 | 공격속도 | 내구도 |
|---|---|---|---|---|
| 이지피아 (`stellive:easypia`) | 철검 | 11 | 1.6 | 무한 |

- 명령어: `/give @s stellive:easypia`
- 크리에이티브 인벤토리 오른쪽 위 페이지를 넘기면 나오는 **Stellive** 탭에서 꺼낼 수 있어요.
- 인챈트 테이블/모루로는 인챈트할 수 없어요.
- **R키 대쉬:** 이지피아를 들고 R키를 누르면 바라보는 방향으로 약 8칸 대쉬해요. 대쉬 중 근처 엔티티에게 22 피해(체력 30% 이하면 999 피해)와 칼날 색 검궤적 3개. 출발할 때 바람 소리와 구름 파티클. 재사용 대기 1초.
- **우클릭으로 방패처럼 막을 수 있어요.** 성능은 바닐라 방패와 같고, 도끼 등 어떤 공격으로도 막기가 비활성화되지 않아요.
