# Stellive 모드

마인크래프트 **26.3** / **Fabric** 모드입니다.

## 추가되는 아이템

| 아이템 | 텍스처 | 공격력 | 공격속도 | 내구도 |
|---|---|---|---|---|
| 이지피아 (`stellive:easypia`) | 철검 | 11 | 1.6 | 무한 |

- 명령어: `/give @s stellive:easypia`
- 크리에이티브 인벤토리 오른쪽 위 페이지를 넘기면 나오는 **Stellive** 탭에서 꺼낼 수 있어요.
- 인챈트 테이블/모루로는 인챈트할 수 없어요.
- **R키 대쉬:** 이지피아를 들고 R키를 누르면 바라보는 방향으로 약 9칸 대쉬해요. 대쉬 중 근처 엔티티에게 22 피해(체력 30% 이하면 999 피해)와 칼날 색 검궤적 3개. 출발할 때 바람 소리와 구름 파티클. 재사용 대기 13초 (아이템 칸에 엔더 진주처럼 표시, 쿨타임 중에도 막기 가능).
- **우클릭으로 방패처럼 막을 수 있어요.** 성능은 바닐라 방패와 같고, 도끼 등 어떤 공격으로도 막기가 비활성화되지 않아요.

## 사랑이 (`stellive:sarangi`)

- 좌클릭 발사: 한 발 7 피해, 머리 11 피해. 총알 궤적은 애쉬 파티클
- 우클릭(누르고 있기) 조준: 탄퍼짐/반동 감소, 화면 확대
- 탄창 17발 (내구도 막대로 표시), 다 쓰면 1.5초 자동 장전
- R키: 뒤로 대쉬 (살짝 위로). 대쉬 후 2초 안에 맞히면 피해 2배 + 구속 2 (6초). 재사용 대기 4초
- 조합법: 가운데 줄 [네더라이트 주괴][철 주괴][페토], 아래 줄 오른쪽 [철 주괴]

## 페토 (`stellive:peto`)

- 조합법: [하늘색 양털 계단][마법이 부여된 황금 사과][분홍색 양털 계단] / [하늘색 양털][분홍색 양털][분홍색 양털] / [분홍색 양털][분홍색 양털][노란색 양털]

## 함마린 (`stellive:hammarin`)

- 공격력 5.5, 공격속도 1.7, 내구도 무한, 인챈트 불가
- R키 스킬: 3초 동안 신속 3 + 주변 3칸 적에게 매 틱 피해(3초 합계 9), 넉백, 크리티컬 파티클. 재사용 대기 10초 (살아있는 엔티티 전부 맞음. 갑옷 거치대와 내가 길들인 동물은 제외)
- 조합법:

```
 [ ]  [막대기] [ ]
 [ ]  [막대기] [ ]
 [실] [청금석] [실]
```

## 건틀릿 (`stellive:gauntlet`)

- 왼손에 들면 공격 피해 +2
- 주 손에 이지피아, 왼손에 건틀릿을 들면 저항 1 + 속도 1
- 왼손에 들고 있으면 무기(검, 도끼, 곡괭이, 삽, 괭이, 창, 철퇴, 삼지창, 활, 석궁)를 든 상대에게 받는 피해 50% 감소
- 주 손 이지피아 + 왼손 건틀릿으로 공격하면 상대 방패를 5초 동안 못 쓰게 함 (도끼처럼)
- 조합법:

```
 [철 주괴] [철 주괴] [철 주괴]
 [철 주괴] [피아]    [철 주괴]
 [ ]       [철 주괴] [ ]
```

## 피아 광석

- 일반 돌 속에 생겨요 (Y 0~48, 심층암 광석은 없음). 청크당 70% 확률로 한 번, 1개(80%) 또는 2개(20%).
- 네더라이트 곡괭이로 캐야 피아가 나와요. 단단함은 고대 잔해의 0.8배.
- 폭발로 부서지지 않아요.

## 조합법

